## 2. 首次配置（欧拉，一次性）

```bash
# 2.1 关 SELinux / 防火墙
sudo setenforce 0
sudo sed -i 's/^SELINUX=enforcing$/SELINUX=disabled/' /etc/selinux/config
sudo systemctl stop firewalld && sudo systemctl disable firewalld

# 2.2 主机名 / 时区 / 基础工具
sudo hostnamectl set-hostname euler-ibmcp
echo "192.168.80.135 euler-ibmcp" | sudo tee -a /etc/hosts
sudo timedatectl set-timezone Asia/Shanghai
sudo dnf update -y
sudo dnf install -y git wget curl vim-enhanced net-tools chrony tar gzip unzip htop lsof strace
sudo systemctl enable --now sshd chronyd
```

静态 IP（按实际网段改）：

```bash
sudo nmcli connection modify "ens33" ipv4.method manual \
  ipv4.addresses 192.168.80.135/24 ipv4.gateway 192.168.80.2 \
  ipv4.dns "192.168.80.2 8.8.8.8"
sudo nmcli connection up "ens33"
```

免密（Windows PowerShell）：

```powershell
ssh-keygen -t ed25519 -f "$env:USERPROFILE\.ssh\ibmcp_euler"
```

## 6. 部署

### 6.1 补传 backend 并配置

```powershell
scp -r "E:\999-Dev\01-IBMCP-黑盒管控系统\02-IBMCP\backend" meng@192.168.80.135:/home/meng/ibmcp/
```

```bash
cd /home/meng/ibmcp/backend && cp .env.example .env
```

`.env` 必改：

```ini
APP_ENV=production
PG_HOST=127.0.0.1
REDIS_URL=redis://127.0.0.1:6379/0
COLLECTOR_BACKEND=native
```

### 6.2 建表

```bash
cd /home/meng/ibmcp && source venv/bin/activate
cd backend && alembic upgrade head
PGPASSWORD=ibmcp psql -U ibmcp -h 127.0.0.1 -d ibmcp -c "\dt"
```

### 6.3 前端构建 + 上传

```powershell
cd E:\999-Dev\01-IBMCP-黑盒管控系统\02-IBMCP\frontend
npm install; npm run build
ssh meng@192.168.80.135 "rm -rf /home/meng/ibmcp/frontend-dist/*"
scp -r dist\* meng@192.168.80.135:/home/meng/ibmcp/frontend-dist/
```

```bash
chmod -R o+rX /home/meng/ibmcp/frontend-dist
sudo nginx -t && sudo nginx -s reload
```

### 6.4 起服务

```bash
sudo cp /home/meng/ibmcp/packaging/systemd/ibmcp-api.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now ibmcp-api
systemctl status ibmcp-api
```

联调期不用 systemd 时：

```bash
cd /home/meng/ibmcp && source deployments/openeuler/dev-env.sh
ibmcp-api-native
```

## 10. 卡住了先查这几条

| 现象 | 处理 |
|------|------|
| SSH / ping 不通 | 桥接网卡、`firewalld` |
| Docker 拉镜像失败 | 配 `registry-mirrors`，重启 docker |
| `Python.h` 缺失 | `sudo dnf install -y python3-devel` 后重跑 build |
| `_core` 导入报符号错误 | 欧拉误用了 uv 的 Python，改用系统 python3.11 |
| 前端 403 / 404 | `chmod o+x /home/meng`、`nginx -s reload` |
| `/api` 502 | `systemctl status ibmcp-api`，确认 8000 在监听 |
| WS 握手失败 | Nginx 里 `ws` location 必须在 `/api/` 之前 |

完整排查表见 09 §10。
